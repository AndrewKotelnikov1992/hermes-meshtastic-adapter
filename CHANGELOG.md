# Changelog

All notable changes to this project will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Cross-device serial auto-discovery on Linux, macOS, and Windows.
- Selection across multiple serial candidates using optional local-node identity checks.
- GitHub Actions test and lint workflow.
- Public documentation, security policy, roadmap, and MIT license.

## [0.1.0] - 2026-09-02

### Added

- Hermes Agent platform adapter for Meshtastic direct messages.
- USB hotplug and automatic reconnect supervisor.
- Node-ID allowlist, DM-only filtering, duplicate suppression, and UTF-8-safe chunking.
- Real-radio smoke test validated with two Heltec V4 nodes.
